## Extraction integrity and limits

The available Python installations checked lacked `pypdf`, `pdfplumber` and PyMuPDF. No dependencies were installed. Both PDFs use uncompressed content streams, Type1 Helvetica/Helvetica-Bold and WinAnsi encoding. The [standard-library extractor](evidence/extract-questionnaires.py) follows page-tree order and validates counts, stream byte lengths, every `Tj` text operator, absence of unsupported text operators and every printed page footer. It extracted all text objects on all 18 pages. This is complete text reading of these particular exports, not a rendered PDF layout review or general-purpose parser.

Register page references are **1-based PDF pages**, matching printed footers. Document date is the printed generation date, not an assumed approval timestamp. Neither PDF identifies a named respondent or contact email.
